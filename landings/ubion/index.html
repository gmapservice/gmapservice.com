// PREGUNTAS FRECUENTES

¿Qué puedes conectar con Ubion?

Conoce algunos aspectos importantes sobre dispositivos y telemetría.

¿Ubion funciona con diferentes marcas de GPS?＋

Ubion está orientado a soportar diferentes dispositivos de geolocalización y telemetría. La compatibilidad concreta depende del protocolo, modelo y configuración del equipo.

¿Puedo monitorear temperatura?＋

Sí, es posible consultar información de temperatura cuando se cuenta con un dispositivo y sensor compatible, correctamente instalados y configurados.

¿Solo muestra la ubicación de los vehículos?＋

No necesariamente. Según las capacidades del hardware conectado, también puede recibir variables de telemetría, estados y eventos adicionales.

¿Ubion se puede integrar con otros sistemas?＋

Las posibilidades de integración se revisan según los servicios, APIs y mecanismos de intercambio disponibles. Podemos evaluar el escenario de tu empresa.
